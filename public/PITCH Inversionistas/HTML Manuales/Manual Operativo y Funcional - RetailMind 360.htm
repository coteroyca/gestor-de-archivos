Manual Funcional, Operativo y de Recursos del Equipo

1. Estructura Organizacional y Roles del Equipo

Estructura operativa jerárquica diseñada para maximizar la velocidad de desarrollo garantizando el control de calidad absoluto y el resguardo del código fuente.

Jefe de Desarrollo / Lead Developer (1 Puesto)

Responsabilidad: Líder técnico y administrador principal del ecosistema. Coordina la arquitectura del software, gestiona las políticas de la organización en GitHub, asigna tickets de trabajo, aprueba fusiones críticas de código a producción en Vercel y supervisa la seguridad perimetral.

Desarrolladores Core / Personal de Planta (2 Puestos)

Responsabilidad: Ingenieros de software internos encargados del núcleo de la aplicación central a largo plazo. Tienen acceso total de lectura/escritura en los repositorios principales. Su función operativa crítica es actuar como Revisores Obligatorios de todo el código enviado por el personal externo.

Desarrolladores Independientes / Freelancers (2 Puestos)

Responsabilidad: Programadores externos contratados para resolver tareas puntuales, módulos aislados, landing pages promocionales o mantenimiento específico. Trabajan en ramas de código aisladas (branches) y tienen estrictamente prohibido el acceso directo a los servidores de producción o bases de datos principales.

2. Ecosistema de Software y Tecnologías (Stack de Desarrollo)

Gobernanza de las herramientas de software empleadas para el diseño, maquetación, programación y asistencia del equipo:

Cursor (El Editor de Código)

Entorno de desarrollo integrado (IDE) principal del equipo. Reemplaza al VS Code clásico, permitiendo interactuar de manera nativa con modelos de Inteligencia Artificial directamente sobre los archivos del proyecto.

Claude (Anthropic IA)

Cerebro analítico principal para programación compleja, resolución de algoritmos y depuración. Incluye el uso de Claude Code en la terminal para refactorizaciones automáticas locales.

v0 by Vercel

Generador de interfaces Front-end mediante lenguaje natural. Utilizado para maquetar pantallas y prototipos visuales interactivos exportables directamente hacia Cursor.

Gemini (Google IA)

Herramienta secundaria de asistencia técnica. Excelente para procesamiento de grandes volúmenes de documentación técnica externa y análisis veloz de datos adjuntos debido a su ventana de contexto masiva.

Nano Banana

Motor de Inteligencia Artificial especializado en generación de imágenes comerciales y recursos multimedia optimizados. Su uso está orientado al desarrollo visual de catálogos y material promocional.

Tailwind CSS & Bootstrap

Frameworks de diseño responsivo. Tailwind se utiliza como estándar en las aplicaciones modernas conectadas a v0, mientras que Bootstrap se reserva para interfaces tradicionales de rápida maquetación.

Fontawesome & HTML5

Estándar estructural y librería de iconos vectoriales global del proyecto. Garantiza una iconografía ligera, uniforme, escalable y semánticamente limpia en todos los desarrollos web.

PHP & jQuery

Tecnologías del ecosistema secundario. Utilizadas en el hosting compartido para el mantenimiento seguro de sistemas legados, procesamiento de scripts rápidos y manipulación ágil del DOM en módulos simples.

Python

Lenguaje de propósito general incorporado para scripts de automatización de datos, procesamiento de tareas en segundo plano complejas, e integraciones avanzadas con las APIs de Inteligencia Artificial.

MySQL

Motor de bases de datos relacionales. Almacena de forma estructurada los registros de usuarios, configuraciones, sistemas tradicionales y bitácoras operativas dentro del entorno administrado.

3. Plataformas Cloud y Recursos de Hardware (Estructura de Activos)

Inventario y asignación de todos los recursos físicos y de infraestructura en la nube necesarios para la operación global del proyecto RetailMind 360:

A. Recursos de Infraestructura en la Nube (Cloud & DevOps)

  • Vercel Pro: Servidor de despliegue continuo y hosting perimetral global. Procesa las aplicaciones principales y aloja las funciones serverless de la plataforma.
  • GitHub Enterprise/Team: Plataforma central de control de versiones. Repositorio maestro donde reside el activo intelectual más importante de la empresa (el código fuente).
  • Spaceship (Hosting Compartido): Servidor de servicios complementarios. Aloja de forma segura el servidor de correos corporativos (IMAP/SMTP), bases de datos MySQL secundarias y automatizaciones Cron.
  • Cloudflare (Security Perimetral): Capa de protección perimetral contra ataques DDoS, optimización de caché global, gestión centralizada de registros DNS y emisión automatizada de certificados de seguridad SSL.
  • Tailscale (Mesh VPN - Zero Trust): Red virtual privada del equipo. Conecta de forma segura las computadoras locales de los desarrolladores de planta y servidores de prueba sin exponer puertos a internet.
  • PostgreSQL / Supabase (Omitido Esencial): Capa de base de datos moderna agregada. Necesaria para soportar las aplicaciones en tiempo real desplegadas en Vercel, ya que el MySQL del hosting compartido no es óptimo para conexiones masivas Serverless.

B. Recursos de Hardware Requeridos (Estaciones de Trabajo y Periféricos)

  • Estaciones de Trabajo Core (Desarrolladores de Planta): Computadoras portátiles de alto rendimiento (Recomendado: Apple MacBook Pro Apple Silicon o laptops Windows Core i7/Ryzen 7 con mínimo 16GB en RAM y discos SSD NVMe). Equipos provistos por la empresa para garantizar la compilación local ágil.
  • Estaciones de Trabajo Externas (Freelancers): Hardware propio (BYOD - Bring Your Own Device). Deben cumplir con requerimientos mínimos de seguridad impuestos por el Jefe de Desarrollo (sistemas operativos actualizados y cifrado de disco activo).
  • Dispositivos de Autenticación de Doble Factor (2FA): Teléfonos inteligentes corporativos o llaves de seguridad físicas (Yubikeys) obligatorias para el Jefe de Desarrollo y personal de planta para autorizar accesos a GitHub, Vercel y Cloudflare.

4. Flujo Operativo y Políticas de Control (Workflow de Seguridad)

Para evitar fallos en producción y asegurar un rendimiento óptimo, el equipo operará bajo el siguiente flujo estrictamente controlado por el Jefe de Desarrollo:

  1. Diseño y Maquetación: Los programadores diseñan vistas en v0 de Vercel, agilizando el front-end con Tailwind y componentes prefabricados.
  2. Desarrollo Local Avanzado: El código se descarga a las computadoras locales y se edita dentro de Cursor, utilizando Claude Code para estructurar la lógica compleja y conectar las bases de datos de forma inteligente.
  3. Aislamiento de Seguridad (VPN): El acceso a las bases de datos de desarrollo y servidores internos se realiza exclusivamente con la VPN de Tailscale activa.
  4. Control de Cambios en GitHub: Los freelancers suben sus tareas únicamente a ramas secundarias. GitHub bloquea la integración automática mediante sus reglas de Ramas Protegidas.
  5. Revisión de Código (Code Review): Uno de los programadores de planta o el Jefe de Desarrollo audita manualmente el código del freelancer. Si cumple con los estándares, aprueba el Pull Request.
  6. Despliegue Automatizado en Vercel: Al fusionarse el código aprobado, Vercel detecta el cambio en GitHub y compila la nueva versión hacia producción en segundos, notificando al equipo.
