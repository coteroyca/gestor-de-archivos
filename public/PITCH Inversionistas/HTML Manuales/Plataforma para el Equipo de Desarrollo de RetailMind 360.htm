1. Componentes de la Plataforma (Por qué y Para qué)

Estructura modular optimizada para un equipo de 4 personas (2 desarrolladores de planta y 2 programadores independientes/freelance trabajando de forma aislada).

Vercel Pro $80.00 / mes

¿Por qué?: Aloja la infraestructura principal y aplicaciones modernas (Front-end/Serverless) sin costos de administración de servidores ni complejas tareas de DevOps.

¿Para qué?: Despliegue automático de código, hosting optimizado globalmente en la periferia (Edge) y generación automatizada de entornos de pruebas.

Claude Pro (4 Licencias Individuales) $80.00 / mes

¿Por qué?: Es la vía más económica para habilitar la suite completa de desarrollo con IA para las 4 personas, esquivando los mínimos de asientos de los planes corporativos.

¿Para qué?: Uso diario del chat web para diseño de arquitectura técnica y uso nativo de Claude Code dentro de la terminal para programación automatizada en local.

GitHub Team (Organización Centralizada) $16.00 / mes

¿Por qué?: Custodia y centraliza la propiedad intelectual bajo el control exclusivo de la empresa, aislando el código y los permisos de las cuentas externas.

¿Para qué?: Configurar reglas de aprobación de código (Ramas Protegidas). Impide que los freelance fusionen código a producción sin la revisión técnica previa de un programador de planta.

Hosting Compartido (cPanel / Alternativo) $3.00 / mes

¿Por qué?: Provee servicios de infraestructura tradicionales muy estables a bajo costo, liberando al equipo de tener que configurar y parchar un servidor VPS.

¿Para qué?: Operar las cuentas de correo corporativo oficiales del equipo, automatizar tareas rutinarias (Cron jobs base) y desplegar bases de datos de apoyo MySQL o scripts auxiliares en PHP.

Dominios Corporativos (.com Standard) $3.00 / mes

¿Por qué?: Asegura la identidad e imagen digital de las marcas a largo plazo con tarifas planas y predecibles mediante compras trianuales.

¿Para qué?: Mantener activos e independientes un máximo de 3 dominios corporativos con sus respectivas configuraciones de correo electrónico.

Cloudflare (Plan Gratuito) $0.00

¿Por qué?: Funciona como un escudo perimetral inteligente de seguridad entre los registradores de dominios y tus servidores web.

¿Para qué?: Bloquear ataques informáticos de saturación (DDoS) para mitigar costos sorpresa en Vercel, proveer certificados SSL automáticos y segmentar el tráfico de red de forma óptima.

3. Anexo: Glosario de Tecnologías Clave

Claude Code

Herramienta avanzada de interfaz de líneas de comando (CLI) provista por Anthropic. Permite que el motor de IA acceda directamente al directorio de trabajo local del desarrollador mediante la consola, permitiéndole analizar la arquitectura completa de un sistema, corregir fallos sintácticos complejos y actualizar componentes de manera simultánea sin salir de la terminal.

v0 by Vercel

Herramienta de Inteligencia Artificial especializada en diseño generativo de interfaces (Front-end). Transforma instrucciones descriptivas en lenguaje natural en componentes interactivos limpios estructurados bajo tecnologías líderes como React y Tailwind CSS, ahorrando cientos de horas de maquetación visual.

Ramas Protegidas (Protected Branches)

Directrices restrictivas de seguridad configuradas en GitHub. Bloquean la inyección directa de código a los repositorios de producción por parte de usuarios externos o independientes, garantizando que todo cambio deba ser validado y aprobado manualmente por un ingeniero de planta.

Registros DNS (Domain Name System)

Tablas de traducción de redes informáticas encargadas de direccionar solicitudes en internet. Habilitan la bifurcación operativa para que un mismo dominio web cargue su aplicación principal directamente desde los servidores de Vercel mientras mantiene el flujo y resguardo de sus correos electrónicos corporativos en el hosting compartido.
